# dm-skincare-analysis

A statistical analysis repository covering 172 products from dm.de's Serum & Kur category
(skincare serums). Using price, rating, and ingredient data, this project tests a series
of hypotheses about how these products are formulated and priced.

# Analysis A: Ingredient Placement vs. Price

Tests, across 171 products in dm.de's Serum & Kur category, whether
**higher-priced products list active ingredients higher on the ingredient panel.**

## Conclusion (up front)

**The hypothesis was not supported for any of the 9 ingredients tested**
(hyaluronic acid, niacinamide, vitamin C, retinol, panthenol, allantoin, squalane,
lactic acid, and salicylic-acid-family BHAs). Using brand-level cluster bootstrap
95% confidence intervals, every one of the 9 ingredients had an interval that
crossed zero.

Along the way, the analysis uncovered a methodological pitfall: the normalized
rank metric (`rank_norm = rank ÷ total ingredient count`) turns out to be confounded
by ingredient count itself, which correlates with price and can produce a spurious
correlation.

See the [Zenn article (Japanese)](https://zenn.dev/yuki_hogehoge/articles/dm_serum_analysis_ingredient_rank)
and the notebook itself for full details.

## How to Run

```bash
pip install -r requirements.txt
```

With `skincare_dataset_final.csv` placed in `analysis_A_ingredient_rank/`, running the

| 11 | Summary figure (forest plot) |
| 12 | Conclusions and limitations |

## Statistical Methods

- **Spearman rank correlation**: used to assess the relationship between price and
  ingredient placement (normalized rank / absolute rank), since it is robust to outliers.
- **Bootstrap confidence intervals** (both product-level and brand-cluster-level):
  used to quantify uncertainty around point estimates, not just report them.
- **Partial correlation**: used to control for the confounding effect of ingredient count.

These functions have been extracted into `common/stats_utils.py` for reuse in
subsequent analyses (B, C, D, etc.).

## Limitations

- Price does not account for product volume (ml) — this is not a price-per-100ml comparison.
- Ingredient rank is an imperfect proxy for concentration: under EU labeling rules,
  ingredients below 1% concentration may be listed in any order.
- The dataset covers 171 dm.de products at a single point in time; findings do not
  generalize to the broader market or other time periods.
- The partial correlation is a simplified version that removes the linear effect of
  ingredient count; nonlinear confounding may remain.
